# moon_shadow_example

A module that reads **its own** `moon.mod` at runtime through `moon_shadow`.

```moonbit nocheck
let info = @moon_shadow.current()
println(info.name)    // "PaiGack/moon_shadow_example"
println(info.version) // "0.2.6"
```

Run it from this directory:

```
moon run --target js cmd/main
```

## How the metadata gets in

`moon_shadow` reads metadata through the virtual package
`PaiGack/moon_shadow/shadow`. This module implements it in `shadow/`
and points `overrides` at that package:

```moonbit nocheck
options(
  overrides: [ "PaiGack/moon_shadow_example/shadow" ],
)
```

`shadow/generated.mbt` is committed, so a clean clone needs no extra step.
It is regenerated by the `gen` rule in this module's `shadow/moon.pkg`, on
every `moon check`, from this module's `moon.mod` — so editing `moon.mod` is
enough, no separate generation step. The generator is the published
package's `gen` package, run straight out of `.mooncakes` where `moon add`
stages it, so this module needs nothing but the registry dependency.
